# WebApplication1

📌 Project Description
This is a web application developed using ASP.NET WebForms. It includes features like user registration, login system, and admin panel.

🛠️ Technologies Used
- ASP.NET WebForms
- C#
- HTML, CSS, JavaScript
- SQL Server

⚙️ Requirements
- Visual Studio 2022
- .NET Framework 4.7.2
- SQL Server

🚀 How to Run the Project
1. Clone the repository:
   git clone https://github.com/yourusername/WebApplication1.git
2. Open the project in Visual Studio 2022
3. Restore NuGet packages (if needed)
4. Configure database:
   - Update connection string in `web.config`
5. Run the project (Press F5)

🗄️ Database Setup
- Import the provided `database.sql` file into SQL Server
- Update connection string accordingly
